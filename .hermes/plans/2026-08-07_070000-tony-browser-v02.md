# Tony Browser v0.2 Implementation Plan

> **For Hermes:** Implement plan này task-by-task. Mỗi task commit riêng.

**Goal:** Tony Browser v0.2 — browser dùng được thật: tab, thanh địa chỉ, duyệt web với Privacy blocklist cơ bản.

**Architecture:** Electron main process quản lý các `WebContentsView` (mỗi tab 1 view). Renderer React (Vite) hiển thị TabBar + AddressBar, giao tiếp qua IPC `contextBridge` (`window.tony`). Privacy chặn request qua `session.webRequest` với blocklist JSON.

**Tech Stack:** Electron 31, React 18 + TypeScript, Vite (electron-vite), electron-store, Vitest.

**Tài liệu tham khảo:** `docs/TECHNICAL.md` (kiến trúc chi tiết).

**Step 2:** Run `npm test` — expected: FAIL (module chưa có).

**Step 3:** Tạo `src/main/tabs/TabManager.ts`:
```ts
import { EventEmitter } from 'events'

export interface View { id: string; loadURL(u: string): void; destroy(): void }
export type ViewFactory = (id: string) => View

export interface Tab {
  id: string; url: string; title: string; loading: boolean; view: View
}

export function createTabManager(factory: ViewFactory) {
  const emitter = new EventEmitter()
  const tabs = new Map<string, Tab>()
  let activeId = ''
  let counter = 0

  function open(url: string): Tab {
    const id = `tab-${++counter}-${Date.now()}`
    const view = factory(id)
    const tab: Tab = { id, url, title: 'New Tab', loading: true, view }
    tabs.set(id, tab)
    activeId = id
    view.loadURL(url)
    emitter.emit('changed', { type: 'open', id })
    return tab
  }

  function close(id: string) {
    const tab = tabs.get(id)
    if (!tab) return
    tab.view.destroy()
    tabs.delete(id)
    if (activeId === id) {
      const remaining = [...tabs.keys()]
      activeId = remaining.length ? remaining[remaining.length - 1] : ''
    }
    emitter.emit('changed', { type: 'close', id })
  }

  function activate(id: string) {
    if (!tabs.has(id)) return
    activeId = id
    emitter.emit('changed', { type: 'activate', id })
  }

  function list(): Tab[] { return [...tabs.values()] }
  function getActive(): Tab | undefined { return tabs.get(activeId) }

  return { open, close, activate, list, getActive, on: emitter.on.bind(emitter), get activeId() { return activeId } }
}
```

**Step 3:** Implement `blocklist.ts`:
```ts
export function createBlocklist(domains: string[]) {
  const set = new Set(domains)
  return {
    shouldBlock(url: string): boolean {
      try {
        const host = new URL(url).hostname
        return set.has(host) || [...set].some(d => host.endsWith('.' + d))
      } catch { return false }
    }
  }
}
```

import { session } from 'electron'
export function enablePrivacyFilter(blockedCallback: (n: number) => void) {
  const bl = createBlocklist(require('./blocklist.json'))
  let count = 0
  session.defaultSession.webRequest.onBeforeRequest({ urls: ['*://*/*'] }, (details, cb) => {
    if (bl.shouldBlock(details.url)) { count++; blockedCallback(count); cb({ cancel: true }) }
    else cb({})
  })
  return { getCount: () => count }
}

## Ghi chú môi trường (Pitfalls)

- **Server headless:** electron cần `--no-sandbox` + `xvfb-run`; cần libs: `libgtk-3-0 libnss3 libgbm1 xvfb libasound2` (đã cài).
- **Ổ đĩa /data nhỏ (434M):** luôn cài npm với `--cache /tmp/npm-cache`, `ELECTRON_CACHE=/tmp/electron-cache` để tránh ENOSPC.
- **Git push:** token trong `/data/.hermes/.env` (`github_token=`), push qua URL `https://x:TOKEN@github.com/hungtvb/tony-browser.git`.
